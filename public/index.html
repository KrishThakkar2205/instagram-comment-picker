One-time Setup Required

  1. 1
    Go to developers.facebook.com → Create App → Add Instagram Platform
  2. 2
    Under Instagram → API Setup with Instagram login, copy your App ID and App Secret
  3. 3
    Add this to Valid OAuth Redirect URIs:
    http://localhost:3000/api/auth/callback
  4. 4
    Open .env in this project folder and fill in: 
    INSTAGRAM_APP_ID=your_id_here
INSTAGRAM_APP_SECRET=your_secret_here
  5. 5
    Restart the server with npm start, then click Continue with Instagram above
